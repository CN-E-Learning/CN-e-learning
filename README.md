# CN-e-learning 电教委员指南

![banner](public/images/og-image.png)

<pre>CN-e-learning 是一个专注于帮助电教委员提升工作能力的指南项目。本指南由顶尖电教委编撰，内容涵盖多种计算机知识、错误应对方法等，旨在助力每一位电教委员成为优秀的技术支持角色。</pre>

</div>

> 本仓库存放 CNEL 网站源码，使用 Nuxt 4 框架。详细指南请访问[语雀](https://smartteachcn.yuque.com/zpgkmv/cnel)。

## 功能特性

- 响应式设计
- 深浅色主题切换
- SEO 优化
- 自动生成 sitemap
- 现代化 UI

## 技术栈

Nuxt 4 + Nitro + Vite + Vue

## 开发

安装依赖：

```bash
pnpm install
```

启动开发服务器：

```bash
pnpm run dev
```

## 构建

生成静态文件：

```bash
pnpm run generate
```

预览静态文件：

```bash
pnpm run preview
```

## 部署

生成的静态文件位于 `.output/public` 目录，部署时指向该目录即可。
